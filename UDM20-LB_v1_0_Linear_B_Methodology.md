## Core Position

UDM20-LB is designed for **re-examining "solved" syllabic scripts with remaining gaps**, particularly Bronze Age Aegean administrative systems where:
- conventional decipherment exists but is incomplete,
- certain signs remain ambiguous or multi-valued,
- semantic fields are under-explored,
- cultural context is rich but underutilized,
- and family-script comparison can reveal overlooked patterns.

This framework is built for **Linear B** first, but is intentionally compatible with other Aegean Bronze Age scripts: **Linear A**, **Cretan Hieroglyphs**, **Cypro-Minoan**, and **Phaistos Disc** when cross-comparison is materially valid.

UDM20-LB does **not** begin by assuming:
- that Michael Ventris and John Chadwick achieved complete decipherment,
- that all ambiguous signs are permanently unknowable,
- that administrative texts contain no religious/cultural depth,
- that phonetic values are settled,
- or that Minoan substrate influence is fully mapped.

Instead, it begins from a stricter principle:

> **Even "solved" scripts have gaps. Natural pattern emergence through mega-correlation, family-script comparison, and deep archaeological integration can reveal what conventional approaches missed.**

That includes the possibility that Linear B contains:
- unexplored logographic values,
- Minoan substrate vocabulary,
- ritual formulae embedded in administrative texts,
- phonetic values with regional variation,
- semantic fields requiring cultural re-contextualization,
- or combinations of the above.

UDM20-LB treats gaps not as mysteries, but as **systematic opportunities for natural emergence**.

## Why a Linear B-Specific UDM Is Needed

The generic UDM20 framework is broad and powerful, but Linear B presents a special challenge:

- it's conventionally considered "solved" (Greek identification confirmed),
- but significant gaps remain (ambiguous signs, unclear logograms, semantic drift),
- the corpus is large (~5,000 tablets) enabling statistical validation,
- Minoan family-script comparison is crucial but underutilized,
- palatial administrative context is archaeologically rich,
- and the Minoan substrate influence is incompletely mapped.

This means Linear B requires a tailored adaptation that is:
1. **gap-aware, not solution-accepting,**
2. **Minoan-family comparative,**
3. **palatial-context integrated,**
4. **statistically rigorous (large corpus advantage),**
5. **substrate-sensitive (Minoan → Greek).**

Linear B conventional work remains foundational, but under UDM20-LB it should be treated as **Phase 0 baseline**, not the final word.

## Substrate Vocabulary Extraction Protocol

Identifying non-Greek (Minoan substrate) words:

### Primary Indicators
1. **Phonotactic anomalies** (non-Greek sound combinations)
2. **Linear A cognates** (words appearing in both scripts)
3. **Cultural-specific terminology** (religious, botanical, topographical)
4. **Morphological isolation** (no Greek etymological connection)
5. **Regional concentration** (Cretan tablets only)

### High-Confidence Substrate Examples
- **ku-pa-ro** (κύπαρος kyparos "cypress") - Minoan plant name
- **sa-sa-ma** (σήσαμον sēsamon "sesame") - Eastern Mediterranean loanword
- **da-pu₂-ri-to-jo** (λαβύρινθος labyrinth) - Pre-Greek suffix -νθος
- **mi-ka-ta** (? unclear) - potential Minoan title
- **qe-ra-si-ja** (? unclear) - possible religious term

### Extraction Method
1. Compile all non-Greek-etymological words
2. Check Linear A for cognates
3. Analyze phonotactic patterns
4. Map cultural context (religion, nature, titles)
5. Cross-validate with Cretan Hieroglyphs/Cypro-Minoan
